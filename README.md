Acesta este un ecosistem IoT complet, dezvoltat de la zero, care conectează un prototip hardware de stație de încărcare pentru biciclete electrice cu o interfață web de monitorizare în timp real.

## 📌 Descrierea Proiectului
Proiectul rezolvă problema monitorizării și gestionării stațiilor de încărcare pentru biciclete. Prin integrarea tehnologiilor hardware cu o platformă web modernă, sistemul colectează telemetrie de la nivelul stației și o afișează utilizatorilor într-un mod accesibil.

### ⚙️ Componenta Hardware (Embedded / IoT)
*   **Microcontroler:**  ESP8266 Arduino

*   **Comunicare:** Transmiterea datelor de telemetrie către server 

### 💻 Componenta Software (Web Dashboard)
*   **Frontend & Backend:** Construit cu **Next.js** și **TypeScript** pentru o interfață fluidă și rute API integrate.
*   **Procesare date:** **Python** 
*   **Deployment:** Găzduit pe Vercel, cu actualizări în timp real ale stării stațiilor.
